# Contribution-evidence workflow validation

The review separated instruction consistency from scientific contribution quality.

## Contract checks

- An empirical new-method claim must identify its closest precedent and decisive comparison before drafting.
- A supported synthesis uses an analytical/decision-distinction validation track, not mandatory empirical superiority or Monte Carlo tests.
- A high aggregate grade cannot override an unsupported central contribution.
- A post-draft research gap returns through the existing bounded rethink counter when authorized; otherwise it receives an explicit below-target outcome.
- Code/specification disagreement requires source and derivation reconciliation. Neither is automatically authoritative.
- Diagnostic CSVs and supplementary evidence do not trigger blanket comparator/anomaly placement requirements.

Independent specification and standards reviews initially found conflicting legacy instructions in these paths; those conflicts were corrected and rechecked. Relative shared-contract links and diff whitespace checks passed.

## Local application

Applied to an existing statistics manuscript using the author's source collection and external primary methodological and applied papers. The closest precedents prevented unsupported novelty claims. The revision sharpened a decision-audit contribution, added independently checked deterministic comparisons, retained adverse tradeoffs, and separated hypothetical inputs from a published clinical contrast. Sources and private manuscript artifacts remain outside this repository.

The application supports the workflow's usefulness for a focused synthesis. It does not establish general writing improvement, journal acceptance, empirical clinical impact, or autonomous scientific sign-off. Those remain separate evaluations.
